## 自动验证

```bash
python -m compileall -q src tests
python -m unittest discover -s tests -v
node --check src/myth/webui/app.js
```

50 项测试覆盖原有 P1/P2/P3 与新增边界：

- 错误替换带真实成功 Receipt、无合同、未修改文件被污染、剩余事项均不能交付。
- 固定提交基线，多文件结果与 BOM/CRLF 保留；重复文件名、重复入口冲突拒绝。
- 模型超时 UNKNOWN 不重发；错误 JSON 计费；迟到 Receipt 从 unknown-held 结算一次。
- 模型 I/O 中取消、无 Ticket Intent 取消、过期/重复问题答复、同运行第二驱动器拒绝。
- **真实子进程 `os._exit`**：模型响应已持久化但决策未消费、工具已结算但步骤未完成；重启不增加模型调用或重复 patch，不产生 P1 Agent 交付。
- 本地 HTTP：演示完成、固定字节下载、展示副本变化不污染下载、请求去重、完成前拒绝下载、Origin/Host/Content-Type 限制。
- 必需上下文/完整请求过大在模型 Ticket 前停止；纯 Agent 核心依赖方向守卫。

其中 provider 为确定性实现或测试替身。硬退出测试是实际磁盘/进程恢复验证，不等于真实远端 provider 故障验证。
