# Myth · 可展开的工作台

用户确认「艺术机构：安静、精确、有辨识度」。2026-10-06 修订固定白色 `#F8F4ED`、黑色 `#0E100F`，静态身份采用双眼水平对齐、左右中缝延伸的水墨太极波浪 M，保留本地中文字体和三栏交互。视觉合同见 [DESIGN.md](../DESIGN.md)，页面决策见 [workbench.md](../.impeccable/surfaces/workbench.md)。

## 可以实际操作什么

- 左栏：工作、资料、最近会话分别折叠；收成窄轨道后主入口仍可用，展开时恢复分组偏好。
- 中央：已有会话出现问题目录，按持久消息身份返回原问题；专注模式同时收起两栏，退出时恢复进入前的左右布局和草稿。`Escape` 先归当前弹窗，再用于退出专注。
- 右栏：概览、执行、资源三个观察角度；统计、Goal、交付、执行链、执行图、恢复、轨迹、工具、控制、模型、Tokens、上下文、预算、路径比较、架构状态均保留。每类证据独立折叠，运行与独立验收提示持续可见。
- 中央消息与输入框两侧共享阅读尺度，手机与专注模式保持对齐；新 Run 的中央和右栏同步读取同一投影。
- 子模型默认沿用主模型提供方；上下文窗口及本地服务地址仅在 Ollama 时显示，切换提供方保留原值，凭据依旧走原安全入口。
- 对话框、模型配置及模型建议共用主题化选择器；方向键、首尾键、输入检索及 Escape 均保留，Escape 先关闭菜单再关闭所属弹窗。原字段仍持有配置值，选择器仅负责呈现。
- 主、子模型分别约束数字：采样温度 0–2，Claude 0–1；无原生采样能力时停用并归零。Thinking 使用已查明的原生档位；说明其推理时间及输出 Token 影响。输出上限同时受全局和已知模型能力约束，浏览器与服务端独立校验。
- 主、子模型按提供方和精确模型 ID 自动查询标价，显示每百万 Token 单位、目录来源及查询时间；合同覆盖折叠且默认关闭。未公布、未知、查询失败、本地/托管渠道及订阅均不推断为免费。
- 动效：空间分配 260ms、角度切换 180ms，真实等待使用 14px 太极，2.6 秒匀速转一周；减少动态效果偏好使其静止，手机保留抽屉焦点边界。

`studio.js` 只拥有浏览器布局偏好。业务状态仍由既有 Runtime/仓储持有；切换页面、目录或折叠不授予权限、不创建 Run、不补造进度。已知文字可中文化，未知后端值原样保留。

## 字体与图像

正文采用本地 Noto Sans SC，拉丁文字采用 Manrope，静态标题采用 Noto Serif SC；许可与来源在 [fonts/README.md](../src/myth/webui/fonts/README.md)。完整正文字符表避免中文长尾字形依赖在线服务。`scripts/build_ui_fonts.py` 记录字体子集构建过程。

静态身份采用 [ink-taiji.png](../src/myth/webui/ink-taiji.png)：1918×820 RGBA 透明水墨图，左黑右白、相反鱼眼水平对齐，中缝向两侧拉出连续波浪。由内置图像工具根据上一版编辑生成，完整提示词保存在 [sidecar](../src/myth/webui/ink-taiji.png.json) 及 PNG 元数据中。提示词要求旋转 180° 后重组；它记录设计意图，不构成逐像素旋转证明。

品牌和工作空间显示为 56×24px，折叠轨道宽 36px。四方向 `.3px`、零模糊轮廓从真实 alpha 派生，保证同色背景上两半仍可辨；不添加衬底或改变笔触形状。14px 真实等待及 favicon 保留 [taiji.svg](../src/myth/webui/taiji.svg) 的几何双鱼，以适应微型显示。纸构图案已退出页面、HTTP 和发布包，仅在垃圾站留档。没有远程字体、图库或动效依赖，未新增前端框架。

标价源为固定公共 [models.dev 目录](https://models.dev/)，页面同时链接提供方说明。查询时间表示目录获取时间，不保证官方账单；费用仍为估算，未计缓存折扣。新 Run 冻结报价，恢复和同一请求重试保留原快照；自动报价变化不改变请求身份，手动合同改价仍改变身份。目录 IO 在 Runtime 事务之外，不传递凭据或对话内容。
