# 会话统计

Runtime 第三栏顶部显示当前**整段会话**的四项累计统计；下方 Tokens、Tools、Recovery 等区域仍展示最新 Turn。

| 指标 | 口径 |
|---|---|
| 模型用时 | Runtime 实测模型调用的 wall-clock 毫秒之和，包含认证/网络等待与已知失败，不含等待重连的空闲时间 |
| 工具调用用时 | 已记录工具执行的单调时钟耗时之和，包含结果准备与实际执行，结束于收据发布前；不含恢复等待和收据复用 |
| 首 token 平均（TTFT） | 每次已报告调用从开始到首个非空文本增量的毫秒数，按调用取算术平均；不平均每轮均值 |
| 输出速度（TPS） | **成功调用的输出 token 总量 ÷ 同一批调用的总用时（秒）**，包含 TTFT；不平均每次调用的 TPS |

TPS 只使用同时有有效 token 与正耗时的成功调用。失败、UNKNOWN、缺测、零毫秒分辨率的调用不参与速率。输出 token 使用供应商报告值，包含其计入输出的 reasoning token；这是端到端速度，不是 GPU 解码速度。

缺测显示“未报告”。部分耗时如 `1.5秒 · 1/3` 表示三次记录中只有一次具备耗时，值仅累计已测部分。空会话模型/工具累计为零，TTFT/TPS 尚无样本。Ollama 当前非流式调用不提供可测首文本增量，因此 TTFT 不估算；GPT SSE 使用实际文本 delta。

工具收据与 `workspace_operations.tool_wall_ms` 保存同一实测毫秒，结算原子记入；进程在收据发布后退出，可核对原收据恢复，稳定 `decision_id` 复用不重新计时。旧表增量增加可空列，旧记录不从粗粒度时间戳回填。无计量/坏计量不改变效果核对、授权或预算。

会话读取复用已有模型/工具记录做线性汇总，不新增逐轮数据库查询，也不签发调用。页面计量不变时复用已显示的统计，刷新与重启继续读取持久事实。

回归：`tests/test_session_statistics.py` 覆盖加权口径、缺测/坏值、零、重复身份、跨会话与重启、旧表/收据、真实 `os._exit` 和本机 HTTP；`tests/test_statistics_ui.cjs` 验证同一展示实现的单位及覆盖。夹具不证明真实供应商速度。
